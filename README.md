One image summing up the world news of Tuesday 24 November 2026: 14 dated stories across six regions, each with its sources printed on the card, laid out as a newspaper front page. `entry.png` is the entry; `main.ts` checks the PNG against the gate's limits and copies it to `/output`. The page itself is generated by `draw.py` (layout) and `scenes.py` (one flat vector scene per story), so the picture is drawn rather than assembled. Pressed at ~300 px, the nine grid headlines still read verbatim.

## Run it

```sh
python3 draw.py entry.png     # renders the page from draw.py + scenes.py
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
